Покритий часовий проміжок: 02.10.2022–10.09.2026. Вкладення не потрібні для запитів за текстом і посиланнями; їхній вміст не використовується в публічних матеріалах.

## Можливості для дослідження

- Повнотекстовий пошук повідомлень за українськими, англійськими й російськими ключовими словами.
- Вибірка за датою, автором, відповідями, медіатипом і посиланням.
- Пошук Telegram-, Facebook- та інших URL у контексті повідомлення.
- Виявлення повторюваних практичних питань для подальшої перевірки в першоджерелах.

## Робочий порядок

1. Сформулювати вузьке питання: наприклад, «реальний досвід подання police certificate» або «посилання на міські Telegram-групи».
2. Знайти релевантні повідомлення через повнотекстовий індекс і перевірити контекст діалогу.
3. Відокремити досвід людей від посилань на офіційні правила.
4. Перевірити будь-які імміграційні, юридичні чи медичні твердження в авторитетному першоджерелі.
5. У публічний репозиторій додати лише знеособлений висновок, дату перевірки й URL офіційного джерела. Не додавати цитати з чату або самі приватні посилання.

## Межі даних

Архів показує, що обговорювали люди, але не доводить правильність поради, актуальність лінка або репрезентативність досвіду. Реакції й кількість повторень не є верифікацією. Особливо для IRCC правила має перевагу офіційна сторінка, а не чат.

Технічні показники аудиту й тематичний зріз збережено в [знеособленому дослідницькому артефакті](../../artifacts/research/2026-09-15-telegram-archive-audit.md).
