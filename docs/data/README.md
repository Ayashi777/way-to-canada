# Дані та локальні індекси

Ця папка документує структуру локальних джерел без передачі самих даних у Git. Вона допомагає відтворити пошук, зрозуміти межі висновків і не сплутати досвід із чату з офіційним правилом.

- [Telegram-архів: безпечний локальний індекс](telegram-archive-local-index.md)
- [Правила зберігання й використання Telegram-архіву](telegram-archive-governance.md)

Усі персональні матеріали, експорти й SQLite-файли залишаються локально та виключені через `.gitignore`.
