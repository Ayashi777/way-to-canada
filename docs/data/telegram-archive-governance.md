# Правила роботи з Telegram-архівом

## Рівні доступу

| Рівень | Де зберігається | Що дозволено |
| --- | --- | --- |
| Локальний приватний | SQLite та оригінальний експорт поза Git | Пошук, аналіз контексту, підготовка чернеток висновків |
| Публічний безпечний | Цей репозиторій і GitHub Pages | Агрегати, методологія, перевірені висновки, офіційні URL |

## Ніколи не публікувати

- Текст повідомлень, цитати чи скриншоти без явної згоди автора.
- Імена, username, телефони, ID, адреси, документи, геолокації та персональні історії.
- Інвайт-посилання, закриті групи й інші URL, що можуть порушити приватність або правила спільноти.
- Оригінальний експорт, SQLite-базу, вкладення, `raw_json` та локальні шляхи до файлів.

## Правило для висновків

Кожен публічний висновок із чату позначається як «досвід спільноти», не як правило. Якщо він стосується імміграції, права, здоров'я, фінансів або працевлаштування, поруч має бути перевірене офіційне чи інше авторитетне джерело та дата перевірки.

## Перед комітом

1. Переконатися, що в `git status` немає `*.sqlite`, `result.json`, експорту, вкладень або папки `private/`.
2. Перевірити, що документ містить лише агреговані цифри або власний узагальнений висновок.
3. Прибрати ідентифікатори, цитати й посилання з приватних повідомлень.
4. Додати URL першоджерела, якщо текст може впливати на важливе рішення.
