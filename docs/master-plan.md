Оновлено: 2026-09-15  
Правило: цей файл містить лише погоджений актуальний стан. Історія змін — у `journal/`, причини рішень — у `decisions.md`.

## Найближчий огляд

Під час щоденного огляду підтвердити один конкретний наступний крок для кожного активного напряму і перенести результат до місячного журналу.

## Рішення, які треба погодити

| Напрям | Мінімальний результат огляду | Де фіксувати |
| --- | --- | --- |
| Імміграція та в'їзд | Тип заяви, контрольна дата, перелік доказів і офіційний URL | [статус і візи](immigration/status-and-visas.md), [рішення](decisions.md) |
| PR | 2–3 маршрути, критерії відповідності, критичні документи й дата повторної перевірки | [стратегія PR](immigration/pr-strategy.md) |
| Робота | 1–3 цільові ролі, галузі, мінімальні вимоги й тижнева метрика заявок | [цільові роботодавці](career/target-employers.md) |
| Поселення | Провінція/місто, три сценарії бюджету й резервний варіант житла | [бюджет](settlement/budget.md), [житло](settlement/housing-health-school.md) |
| Мова й навички | Поточний рівень, цільовий результат, дата та спосіб перевірки | [мова й навички](language-and-skills.md) |
