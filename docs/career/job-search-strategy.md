# Стратегія пошуку роботи

Оновлено: 2026-09-15.

## Ритм на тиждень

1. Оновити перелік цільових вакансій.
2. Підготувати адаптовані заявки для пріоритетних ролей.
3. Зробити персональні звернення або follow-up.
4. Зафіксувати в журналі кількість заявок, результат і один наступний крок.

Для кожної важливої заявки персональну версію CV і листа зберігайте локально. У GitHub — лише знеособлений підсумок.
