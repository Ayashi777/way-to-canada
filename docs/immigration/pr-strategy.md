# Стратегія PR

Оновлено: 2026-09-15. Це порівняння маршрутів, а не вибір програми.

| Критерій | Що зафіксувати |
| --- | --- |
| Право на участь | досвід, освіта, мова, місце проживання, професія |
| Час | дедлайни та час на документи |
| Роботодавець | чи потрібна пропозиція роботи, LMIA або підтримка провінції |
| Ризик | які умови або документи критичні |
| Докази | офіційний URL і дата перевірки |

Не обирайте маршрут лише за порадою з чату. Рішення про основний маршрут фіксується в `docs/decisions.md` після перевірки офіційних критеріїв.
