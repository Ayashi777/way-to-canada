# Статус і візи

Оновлено: 2026-09-15  
Це не персональна юридична порада. Перед поданням звірити вимоги з IRCC та власним статусом.

## Ключовий принцип

Work permit дозволяє працювати у Канаді, але не є документом для подорожі чи повторного в'їзду. Для повернення потрібна чинна TRV або eTA — залежно від громадянства та способу подорожі.

## Безпечний робочий процес

1. Визначити, де фізично перебуває заявник: у Канаді чи за її межами.
2. Перевірити строк дії паспорта, TRV/eTA та work permit.
3. Вибрати процедуру IRCC для подання з Канади або з-за кордону.
4. Зберегти лише безпечний запис про результат у журналі; оригінали документів лишити в `private/documents/`.
