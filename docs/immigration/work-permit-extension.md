# Продовження open work permit

Оновлено: 2026-09-15. Перед дією підтвердити індивідуальну відповідність правилам IRCC.

## Що перевірити

1. Чи був в'їзд до Канади у строк, зазначений IRCC для спеціальних заходів.
2. Чи є чинний open work permit, виданий за відповідними заходами.
3. Чи заявник перебуває в Канаді на час подання та рішення, якщо це вимагає чинна політика.
4. Чи не обмежує строк дії паспорта тривалість документа.
5. Які документи показує онлайн-чекліст IRCC на дату подання.

У журнал записується лише результат перевірки й наступний крок. Копії документів залишаються в `private/documents/`.
