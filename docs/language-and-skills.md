Не публікуйте сертифікати з персональними ідентифікаторами. Достатньо назви, дати та безпечного підсумку.

## Правило вимірювання

Для кожного рядка додайте один вимірюваний результат, дату перевірки й наступну дію: наприклад, результат мовного тесту/пробного тесту, завершений навчальний модуль або підтверджений кейс. Не додавайте сертифікат, номер реєстрації чи персональний профіль.
