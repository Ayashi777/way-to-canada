# Бюджет переїзду

| Категорія | Що врахувати | Де зберігати точні суми |
| --- | --- | --- |
| Подорож | квитки, багаж, трансфер | локальна таблиця |
| Житло | тимчасове проживання, депозит, перший місяць | локальна таблиця |
| Побут | зв'язок, транспорт, базові покупки | локальна таблиця |
| Документи | переклади, довідки, мита, тести | локальна таблиця |
| Резерв | непередбачені витрати | локальна таблиця |

Не додавайте в публічний репозиторій виписки, баланси, номери рахунків чи адресу житла.

## Сценарії для локальної таблиці

| Сценарій | Місто / провінція | Місяців резерву | Найбільше припущення | Умова переходу |
| --- | --- | ---: | --- | --- |
| Мінімальний |  |  |  | робота або стабільне житло підтверджені |
| Базовий |  |  |  | плановий варіант |
| Обережний |  |  |  | затримка роботи або довша тимчасова оренда |

Точні суми, джерела коштів і адреси ведуться тільки локально. У публічному журналі достатньо зафіксувати, який сценарій обрано та дату наступного перегляду.
