# Індекс локальних приватних матеріалів

Це публічний індекс без файлів, персональних даних, номерів документів, адрес, контактів або локальних шляхів. Оригінали зберігаються лише локально в `private/` і ніколи не комітяться.

| Категорія | Приклади того, що зберігати лише локально | Безпечний запис у GitHub |
| --- | --- | --- |
| Документи особи | паспорти, візи, work permit, довідки, свідоцтва | «Документи для пакета перевірено, дата / наступна дія» |
| Особисті дані | адреси, телефони, номери справ, листування | лише статус без ідентифікаторів |
| Фінанси та здоров'я | виписки, податкові файли, медичні документи | тільки назва задачі або дедлайн |
| Telegram | повний JSON-експорт, база SQLite, вкладення | анонімізований висновок або посилання на публічне джерело |
| Секрети | паролі, токени, ключі, приватні URL | не вести навіть у цьому індексі |

Перед публікацією артефакту перевірити, що в ньому немає ПІБ третіх осіб, контактів, адрес, номерів документів або повного тексту приватного листування.
