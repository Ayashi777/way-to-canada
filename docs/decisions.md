# Журнал рішень

Кожне рішення записується в такому форматі: дата, контекст, рішення, причини, відхилені альтернативи, джерела/докази, дата перегляду.

## 2026-09-15 — Публічний GitHub як журнал, не як сховище документів

- **Контекст:** підготовка до переїзду потребує єдиного місця для плану та досліджень, але документи містять чутливі дані.
- **Рішення:** у GitHub зберігаються лише узагальнені плани, посилання, безпечні артефакти й журнал. Усі оригінали документів, персональні дані та Telegram-експорти залишаються локально в `private/`.
- **Причини:** це дає історію рішень без ризику публікації паспортів, адрес, номерів документів, фінансових чи медичних даних.
- **Відхилені альтернативи:** зберігати скани у репозиторії або посилатися на локальні шляхи в публічних документах.
- **Докази:** [repository_restructure_plan.md](../repository_restructure_plan.md), [private-materials-index.md](private-materials-index.md).
- **Переглянути:** перед першим публічним комітом і далі щомісяця.

## 2026-09-22 — OINP Workforce Priority як цільовий PR-маршрут

- **Контекст:** порівняльний аналіз провінційних програм (ON/SK/AB/MB за NOC-відповідністю, мовою, наявністю оффера) завершено 2026-09-17.
- **Рішення:** основний маршрут — OINP Workforce Priority (Онтаріо): job offer + CLB 5+, PR орієнтовно 9–15 міс після номінації. План B — SINP (Саскачеван) як програма, доступна при CLB 4. План C — CEC після 1 року T4-досвіду.
- **Причини:** найкраща NOC-відповідність цільових ролей (NOC 11202/10022), найбільший ринок праці; SINP покриває ризик при повільнішому прогресі мови.
- **Відхилені альтернативи:** AAIP (цільові NOC не підтверджені у tech-списку; Opportunity Stream — 21–27 міс), MPNP без оффера (перевірено: стріми вимагають роботу/оффер або звʼязок з провінцією), BC PNP (вхід для цільових ролей фактично закритий).
- **Докази:** [OINP](https://www.ontario.ca/document/ontario-immigrant-nominee-program-oinp), [SINP](https://www.saskatchewan.ca/residents/moving-to-saskatchewan/immigrating-to-saskatchewan/saskatchewan-immigrant-nominee-program); приватні ревʼю 17.09 (review-P3/P4/P5).
- **Переглянути:** 2026-10-15 або при відкритті реєстрації OINP EOI.

## 2026-09-22 — Болгарія як база подачі до в'їзду

- **Контекст:** фактичне місце перебування на момент подання — Софія, Болгарія; заява на візу подається онлайн.
- **Рішення:** TRV-заявку подано 2026-09-21 з Болгарії; подальші кроки (IME за запитом IRCC, клініка зі офіційного списку панельних лікарів) — звідти ж до в'їзду в Канаду.
- **Причини:** відповідність фактичному місцю перебування; біометрія вже на файлі (CUAET), тому повторний запис у VAC не потрібен.
- **Відхилені альтернативи:** подача з України (не відповідає місцю перебування).
- **Докази:** [біометрія, IRCC](https://www.canada.ca/en/immigration-refugees-citizenship/services/visit-canada/biometrics.html); [список панельних лікарів](https://secure.cic.gc.ca/pp-md/pp-list.aspx).
- **Переглянути:** після рішення по TRV.
