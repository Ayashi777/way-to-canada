# Way to Canada

Особистий статичний трекер переїзду до Канади.

## Локальний запуск

Відкрийте `index.html` у браузері або запустіть будь-який статичний сервер:

```bash
python3 -m http.server 8080
```

## Публікація та домен

Сайт не має бекенду й збирача: його можна опублікувати на GitHub Pages або Cloudflare Pages. Прогрес чекліста зберігається лише у `localStorage` конкретного браузера.
