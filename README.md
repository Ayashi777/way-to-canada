## Як вести проєкт

Після кожної суттєвої дії додайте короткий запис у `journal/YYYY-MM.md`: дата, дія, результат, джерело/артефакт, зміна плану та один наступний крок. Важливі рішення фіксуйте в `docs/decisions.md` разом із причинами, альтернативами й датою перегляду.

Офіційні правила імміграції зберігайте як короткий висновок із URL першоджерела та датою перевірки. Не копіюйте великі сторінки IRCC і не використовуйте неперевірені поради з чатів як правило.

## Приватність

Ніколи не комітьте паспорти, візи, work permit, довідки, адреси, банківські чи медичні документи, Telegram-експорти, особисті контакти, секрети або приватні посилання. Вони зберігаються лише локально у `private/`, яку виключено з Git. Див. [безпечний індекс приватних матеріалів](docs/private-materials-index.md).

## Сайт

GitHub Pages автоматично збирається з allowlist публічних Markdown-документів. Він показує актуальний план, статус напрямів і посилання на безпечні документи. Позначати виконання кроків на сайті не можна: статус змінюється лише після погодженого щоденного огляду та запису в журналі.

## Локальний запуск

Зберіть публічний артефакт, а потім запустіть локальний статичний сервер:

```bash
node scripts/build-site.mjs
cd dist && python3 -m http.server 8080
```
