# Дослідження

Зберігайте тут лише самодостатні, знеособлені матеріали. Назва: `YYYY-MM-DD-тема.md`. На початку кожного файла вкажіть мету, короткий висновок, дату перевірки та першоджерела.

Не додавайте сюди скріншоти кабінетів, особисте листування, повні Telegram-експорти чи документи з персональними даними.
