# Чекліст щоденного огляду

1. Відкрити поточний `journal/YYYY-MM.md`.
2. Зафіксувати перевірені факти: що зроблено, результат і джерело.
3. Якщо змінився курс дій — оновити `docs/decisions.md`.
4. Якщо змінилися офіційні вимоги — оновити стислий висновок, URL і дату перевірки.
5. Визначити один наступний конкретний крок для кожного активного напряму.
6. Перед комітом перевірити `git status`; приватних файлів у переліку бути не повинно.
